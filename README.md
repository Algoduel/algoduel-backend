# Backend

Ответственный: Артём Штанько. Подключается в общий репозиторий `algoduel` как submodule `backend/`.

## Первые задачи

- [ ] HTTP-сервер и структура пакетов (точка входа: `cmd/backend`)
- [ ] WebSocket: комната на двоих, рассылка событий матча
- [ ] Заглушка judge: читает `judge:submissions`, через секунду пишет случайный `api.Result`
- [ ] Состояние матча: раунды, HP, таймер после первого полного решения
- [ ] PostgreSQL: пользователи, матчи, посылки (миграции)

## Дальше

- [ ] Матчмейкинг по рейтингу, дружеский матч по ссылке
- [ ] Рейтинг (Elo или Glicko)
- [ ] Античит: приём пачек лога, проверка «лог воспроизводится в итоговый код», повтор, жалобы

Контракт с judge: репозиторий `algoduel-api` (в общем репозитории папка `api/`). Инфраструктура: `make up` в корне `algoduel`.
